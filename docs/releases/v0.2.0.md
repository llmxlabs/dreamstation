DreamStation v0.2.0 adds automatic display updates, combined collections, and importing artwork from a link.

- Open displays pick up uploads, deletions, replaced media, and playback settings automatically. Stable player endpoints keep syncing across app deployments, with server events and a five-second polling fallback.
- **All artwork** includes every current and future upload, including files outside a collection. Alternatively, check multiple collections to play together; shared artwork appears once.
- **Upload New Art → From a link** imports images and videos from individual X posts, Midjourney jobs, and Grok Imagine share links directly into the local gallery. Preview and select files before adding them, or use `npm run grab -- "POST_URL"` from the command line.
- Imports validate media, avoid duplicate gallery files, and retain source records privately. A local Chromium session handles sites that need sign-in; cookies and passwords are not exported.
- Linux service instructions cover automatic startup after reboot and crash recovery. Release checks reject private gallery files, databases, browser state, and local configuration from Git.

To upgrade, back up the database, `public/uploads/`, `.env`, and any configured import-state directory. Update the source, run `npm ci` and `npm run build`, and restart the service. This release does not change the database schema. Reload existing player tabs once to load the new live-sync client; later library changes appear automatically.

The source release contains application code, documentation, tests, and the existing public demonstration media. It contains no personal gallery, database, local preferences, credentials, or browser profile. The application remains intended for a trusted private network; it has no login system.
